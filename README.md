# TOMAS — агент для програмування у терміналі

ШІ-агент для розробки, який працює у вашому терміналі: читає й редагує файли, виконує команди, шукає в інтернеті, підключається до MCP-серверів і навчається на ваших сесіях.

---

## Важливо перед початком

TOMAS — це бета-версія, яка активно розвивається. Можливі баги, зміни поведінки між оновленнями і не завжди ідеальна робота з деякими провайдерами чи моделями. Регулярно зберігайте важливий код через git і перевіряйте, що робить агент, перш ніж довіряти йому ризиковані дії.

Наразі TOMAS повністю працює тільки на Windows — керування з клавіатури (стрілки, `F5`–`F9`) побудоване на Windows-специфічних засобах.

---

## Встановлення

Потрібен Python 3.10+ (встановлювач сам його знайде або підкаже, де взяти).

Відкрийте PowerShell і виконайте:

```powershell
powershell -ExecutionPolicy Bypass -c "iex (iwr -UseBasicParsing -Uri https://raw.githubusercontent.com/oleksandkov/Agent-For-TOM/main/install.ps1)"
```

Встановлювач створить папку `~/.tomas`, поставить залежності й додасть команду `TOMAS` у `PATH`.

Після завершення відкрийте нове вікно термінала (щоб підхопився `PATH`) і запустіть:

```
TOMAS
```

---

## Оновлення і видалення

```
TOMAS update       # підтягнути свіжу версію з GitHub
TOMAS uninstall     # повністю видалити TOMAS
```

Сесії, налаштування провайдерів та інструкції зберігаються окремо від коду агента, тож `TOMAS update` їх не чіпає.

---

## Перший запуск і перший промпт

1. Наберіть `TOMAS` — відкриється головне меню зі стрілками.
2. Оберіть **Start Chat** (або одразу запустіть `TOMAS --run`).
3. Якщо жоден провайдер ще не налаштований, TOMAS сам підключиться до безкоштовного рівня OpenCode Zen — окремо нічого робити не треба.
4. Напишіть повідомлення і натисніть Enter, наприклад:
   `Покажи файли в цій папці` або `Напиши функцію на Python, яка рахує факторіал`.
5. Коли модель захоче виконати дію (прочитати файл, запустити команду тощо), TOMAS спитає дозволу — залежно від обраного режиму (див. нижче).
6. Наберіть `/` у чаті, щоб побачити всі команди, `/exit` — щоб вийти.

## Дозволи: режими роботи

Перед кожною дією TOMAS оцінює її ризик (читання файлу — низький, запис чи виконання команди — вищий) і питає підтвердження відповідно до обраного режиму. Перемикати можна клавішами `F5`–`F9` або командою `/mode`.

| Режим     | Клавіша | Поведінка |
|-----------|---------|-----------|
| `auto`    | `F5`    | Дії з низьким ризиком (читання, пошук) підтверджуються самі; про інше — питає |
| `default` | `F6`    | Питає підтвердження перед кожною дією |
| `strict`  | `F7`    | Питає завжди і скидає всі раніше видані дозволи |
| `yolo`    | `F8`    | Підтверджує все без питань |
| `bypass`  | `F9`    | Як `yolo`, і додатково сам продовжує довге завдання без питання «продовжити?» (до внутрішнього ліміту) |

Режими `yolo` і `bypass` вимикають запобіжники повністю — використовуйте обережно, особливо в чужому чи важливому коді.

## Безкоштовний провайдер — OpenCode Zen

Не маєте власного API-ключа? OpenCode Zen дає безкоштовний доступ до кількох моделей — саме на нього TOMAS перемикається сам, якщо нічого не налаштовано.

Щоб обрати модель свідомо: **TOMAS → Add or Configure Provider → OpenCode Zen → Connect to Zen** (ключ можна лишити порожнім), потім **Change Model**.

Безкоштовні моделі (список підвантажується наживо з OpenCode Zen, тож може змінюватися):

| Модель                             | Контекст |
|-------------------------------------|----------|
| `big-pickle`                        | 200K     |
| `deepseek-v4-flash-free`            | 200K     |
| `muse-spark-1.2-contributor-free`   | ~1M      |
| `mimo-v2.5-free`                    | 200K     |
| `hy3-free`                          | 190K     |
| `nemotron-3-ultra-free`             | 1M       |
| `nemotron-3.5-lightning-free`       | 262K     |
| `laguna-s-2.1-free`                 | 256K     |

Примітка: не всі безкоштовні моделі однаково добре працюють з TOMAS. Деякі гірше тримають виклик інструментів і довгі задачі — можуть провалювати завдання або відповідати текстом замість дії. Це особливість конкретної безкоштовної моделі, а не помилка TOMAS. Якщо модель поводиться дивно, спробуйте іншу з переліку через Change Model.

Платні моделі Zen (Claude, GPT, Gemini) доступні там само за токен-тарифом.

## Налаштування (Settings)

Меню **Settings** у головному меню (або команда `/settings` у чаті) вмикає й вимикає окремі функції. Налаштування зберігаються між сесіями і не залежать від обраної моделі.

| Перемикач | За замовчуванням | Що робить |
|-----------|------------------|-----------|
| Streaming replies | увімкнено | текст з'являється поступово під час генерації, а не одним блоком |
| Live status | увімкнено | показує поточний етап: аналізує запит / виконує інструмент / обробляє результат |
| Context controls | увімкнено | дозволяє `/clear` (очистити контекст) і `/export` (зберегти розмову) |
| Debug view | вимкнено | запис сирих JSON-запитів, схем інструментів і відповідей API |
| Prefill context | вимкнено | кожна нова сесія починається з блоку історії (розмір налаштовується) |
| Cap every 3rd reply | вимкнено | кожна третя відповідь обмежується 90 токенами, з повідомленням про це |

Перемкнути з чату: `/settings streaming`, `/settings debug` тощо (достатньо початку назви).

Нижче перемикачів є числове налаштування **Prefill size** — скільки саме історії вставляти: 1 000, 10 000, 20 000, 25 000, 50 000 або 100 000 токенів. Меню показує, яку частку вашого вікна це займе.

### Режим налагодження (Debug)

Увімкніть `Debug view` у Settings або наберіть `/debug on`. Далі:

- **Ctrl+Alt+X** — відкриває **окреме вікно**, яке оновлюється в реальному часі: кожен запит і відповідь з'являються там одразу, поки ви працюєте в чаті
- `/debug list` — список останніх викликів моделі
- `/debug <номер>` — конкретний виклик
- `/debug schemas` — JSON-схеми інструментів, надісланих моделі

Окреме вікно потрібне тому, що чат сам керує своїм терміналом — живий лог не може ділити з ним екран. Запис вимкнено за замовчуванням: кожен запит містить усю розмову.

### Збереження розмови

`/export` питає, куди зберегти: корінь проєкту, підпапку `exports/` або власний шлях. Можна вказати одразу: `/export txt D:\мої файли`.

### Автоматичне стиснення контексту

**Context Budget → Auto-compact at** задає, при якому заповненні вікна розмова замінюється стислим переказом. Доступні значення: 4%, 10%, 20%, 25%, 50%, 75% (за замовчуванням), 80%, 90%, 95% або «ніколи».

Низькі значення (4–10%) корисні, щоб побачити стиснення в дії — при 75% від великого вікна воно спрацьовує рідко. `/compact` працює завжди, незалежно від цього налаштування.

## MCP-сервери (вже підключені)

Команда `TOMAS setup` ставить і перевіряє 8 стандартних MCP-серверів — жоден не потребує ключа:

| Сервер                | Для чого |
|------------------------|----------|
| `playwright`           | керування браузером |
| `context7`              | актуальна документація бібліотек |
| `word-docs`             | створення й редагування `.docx` |
| `excel`                 | створення й редагування `.xlsx` |
| `pdf`                   | злиття/розбиття/OCR/таблиці в PDF |
| `fetch`                 | завантаження сторінки як чистого тексту |
| `time`                  | поточний час і часові пояси |
| `sequential-thinking`   | покрокове структуроване міркування |

Для їхньої роботи потрібні `Node.js` (npx) і `uv` (uvx) на комп'ютері. Керування: `TOMAS mcp list / add / remove`.

## Основні команди в чаті

| Команда                    | Що робить |
|------------------------------|-----------|
| `/help`                       | усі команди й гарячі клавіші |
| `/status`                     | модель, контекст, режим, MCP |
| `/model`                      | показати / змінити модель |
| `/provider`                   | показати / змінити провайдера |
| `/mode`                       | показати / змінити режим дозволів |
| `/settings`                   | перемикачі функцій (див. нижче) |
| `/clear`                      | очистити контекст розмови |
| `/export [txt\|json]`         | зберегти розмову у файл |
| `/debug [on\|off\|list]`      | сирі JSON-запити, схеми інструментів і відповіді API |
| `/session`                    | історія сесій: список / зберегти / продовжити |
| `/skills`, `/skill <ім'я>`    | список навичок / запустити навичку |
| `/self-improve` (`/si`)       | що агент вивчив про вас і проєкт |
| `/forget <id>`                | забути вивчений факт |
| `/private`                    | інкогніто-режим — нічого не запам'ятовувати |
| `/exit`                       | вихід |
